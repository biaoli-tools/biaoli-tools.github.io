# 表理工具

**表理工具**是一组面向中文 Excel / CSV 场景的浏览器本地处理工具，适合处理日常办公中的格式转换、乱码修复、去重、合并、拆分和数据差异核对。

在线使用：[biaoli-tools.github.io](https://biaoli-tools.github.io/)

无需注册账号。表格解析、整理和结果生成主要在当前浏览器中完成，本站没有接收表格文件的上传接口。

| 工具 | 适合处理的问题 | 入口 |
| --- | --- | --- |
| CSV / Excel 转换 | CSV、TSV、XLSX 互转，尽量保留前导 0、手机号、订单号和长数字文本 | [打开工具](https://biaoli-tools.github.io/csv-excel-converter/) |
| CSV 中文乱码修复 | 尝试 UTF-8、GBK / GB18030、Big5 编码并重新导出 UTF-8 文件 | [打开工具](https://biaoli-tools.github.io/csv-encoding-fix/) |

| Excel 两列对比 | 找出两列共有值、仅第一列存在和仅第二列存在的内容 | [打开工具](https://biaoli-tools.github.io/excel-two-column-compare/) |

## 为什么使用表理工具

- **文件默认本地处理**：文件内容在浏览器中读取和生成，不需要先上传到本站服务器。
- **不用注册登录**：打开页面即可使用，不需要创建账号。
- **一个页面解决一个任务**：转换、去重、合并、拆分和对比分开处理，减少不必要的复杂操作。
- **处理前后可核对**：工具提供预览、结果统计或差异明细，重要数据建议下载后再次抽查。
- **适合常见办公数据**：重点处理名单、订单、客户编号、部门报表、门店数据等结构化表格。

## 支持范围

目前主要支持：

- `.xlsx`
- `.csv`
- `.tsv`

旧版 `.xls` 请先在 Excel、WPS 或其他表格软件中另存为 `.xlsx`。

为避免浏览器占用过多内存，单个文件超过 20 MB 时会提示性能风险，超过 50 MB 时不会继续处理。多文件任务也设有文件数量和总大小限制。

XLSX 默认使用工作簿中的第一张工作表作为输入数据。宏、图表、数据透视表、外部链接、复杂样式和部分数字格式不会完整保留，因此表理工具更适合整理**数据内容**，不适合复制完整的工作簿版式。

## 数据处理说明

不同工具会根据任务采用相应的数据保护规则，例如：

- CSV 转 XLSX 时尽量把编号、手机号、订单号等按文本保存，减少前导 0 丢失或长数字变成科学计数法的情况。
- CSV 导出默认保护以 `=`、`+`、`-`、`@` 开头的内容，降低被表格软件误识别为公式的风险。
- 按日期去重时，无法识别的日期会停止处理，避免静默选错记录。
- 两个版本对比时，空关键值或重复关键值会被提示，不会直接覆盖或错误匹配。
- 导出 XLSX 时遵循 Excel 单工作表的行列数量限制。

具体规则以各工具页面上的说明和处理结果为准。

## 隐私

表理工具没有用于接收用户表格文件的上传接口。文件内容默认只在当前浏览器中处理。

站点使用访问统计了解页面使用情况，但不会主动把文件名、表头、单元格内容或导出结果作为统计数据发送。浏览器明确发送 Global Privacy Control（GPC）或 Do Not Track（DNT）信号时，站点不会加载访问统计脚本。

完整说明请查看：[隐私政策](https://biaoli-tools.github.io/privacy/)

## 使用提醒

表理工具适合日常数据整理，但自动处理不能替代人工复核。涉及财务结算、法律材料、重要客户数据或其他高风险场景时，请保留原文件，并对关键字段、行数和结果进行人工确认。

如遇到问题，可以通过网站的[关于与反馈](https://biaoli-tools.github.io/about/)页面提交反馈。公开反馈时，请不要上传客户名单、财务数据、身份证明或其他敏感原文件。
